# GASへの反映

1. Apps Scriptエディタで既存ファイルをバックアップします。
2. このフォルダの `Code.gs` でAPI本体を置き換えます。同名関数が二重に残らないようにします。
3. GASでも改善した画面を表示する場合は、HTMLファイルの `index`・`script`・`style` も、このフォルダの同名ファイルで置き換えます。
4. 保存後、「デプロイ」→「デプロイを管理」→既存ウェブアプリの編集→バージョン「新バージョン」で更新します。実行ユーザーとアクセス権限は既存設定を引き継ぎます。
5. APIの既存デプロイを更新すれば `API_URL` は変更不要です。新しいデプロイを別に作成した場合は、画面側の `API_URL` を新URLへ変更する必要があります。
6. 公開URLでホーム・推移・収支・ランキング・明細を確認します。予算作成は書き込みを伴うため、必要なときだけ実行してください。

APIと画面が別のGASプロジェクトの場合は、`Code.gs` をAPI側へ反映します。画面側の既存 `doGet` / `include` は残し、HTML3ファイルを差し替えます。`Code.gs` にはAPIと画面配信の両方の入口が含まれているため、既存構成に合わせて反映してください。

静的サイトはリポジトリ直下の `index.html`・`app.js`・`style.css` を使います。GAS用HTMLを再生成するときは、リポジトリ直下で `node tools/build-gas.cjs` を実行します。
